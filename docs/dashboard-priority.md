# 期限管理ダッシュボードの判定

すべての集計はアクセス時に取引履歴と出品引当から算出する。対象は登録取消されておらず、取引残数が正のロット。口座・制度・名義が停止中でも残数があれば表示する。期限は `Asia/Tokyo` の日付で比較し、期限を過ぎても自動で失効取引は作らない。

| 条件 | 加点 |
| --- | ---: |
| 期限切れ | 100 |
| 今日 | 90 |
| 1〜3日後 | 80 |
| 4〜7日後 | 60 |
| 8〜14日後 | 40 |
| 15〜30日後 | 20 |
| 31日後以降・期限なし | 0 |
| 方針 `sell_now` | 20 |
| 方針 `undecided` | 10 |
| 方針 `self_use` | 5 |
| `sell_now` で出品引当なし | 20 |
| 出品引当あり、期限まで3日以内 | 15 |
| 一部だけ出品引当中 | 10 |
| 期限切れ未処理 | 30 |

優先度の降順、期限の昇順、概算価値の降順、ロット ID の昇順で並べる。出品引当は `listed` 状態の出品だけを合算する。下書きは引当済みと見なさない。

「今すぐ対応」は期限切れ、3日以内、または `sell_now` で出品引当なしのロット。「今週の期限」は今日から7日以内、「30日以内」は8〜30日後。集計カードの「30日以内」には7日以内も含む。「方針未設定」は期限がないロットも含む。同じロットが複数の欄に出ることはあるが、各集計カード内で重複計上しない。

概算価値は `self_use` なら想定利用価値、`sell_now` なら想定売却価値、その他なら額面価値を使う。未設定は 0 円として合計に含めず、個別には「未設定」と表示する。出品中カードの件数は `listed` 出品の重複しない件数、価値は設定済み出品価格の合計。
