# 横断検索 (#10)

`/search` の GET query に検索条件を保持する。`q` は制度名、別名、ロット名、出品タイトル、取引内容、移行、交換ルールを対象にする。保有ロットとロットなし口座残高を別々に集計し、残数ゼロは初期一覧に表示しない。無効な口座と制度も残高がある場合は初期一覧に表示し、`active_only=1` で除外する。

主な条件は `member`、`category`、`program`、`policy`、`restriction`、`expires_within`、`listing`、`transfer_status`。同時指定は AND 条件とする。`preset` は今すぐ対応、期限7/30日、方針未設定、売る予定・未出品、出品中・期限接近、移行予定日超過を提供する。ページングは `lots_page` と `accounts_page` を分離し、query を維持する。

キーワードはパラメータとして SQL に渡し、画面表示は Blade でエスケープする。絞り込み中は、期限などの条件を適用できない別ドメインの候補を混ぜない。移行状態を指定した場合は該当移行を別枠に表示する。
