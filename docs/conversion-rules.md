# 交換ルールと交換ルート

交換ルールは一つの制度から別の制度への交換条件を表す。同じ交換元と交換先の `conversion_rule_group` に、通常、キャンペーン、改定後の `conversion_rule` をバージョンとして保存する。交換率は `to_quantity / from_quantity` から表示時に算出する。過去の移行ステップが参照するルールは残し、条件を変更する場合は新しい版を作る。既存版で修正できるのは手順、公式 URL、メモだけ。移行ステップには作成時に計算した受取予定数量を保存し、後のルール改定で再計算しない。

「現在使える」は `active`、有効開始・終了日、キャンペーン期間を `Asia/Tokyo` の日付で判定する。キャンペーン限定で期間が不明なルールは自動候補に出さない。同じ期間に通常版とキャンペーン版を置ける。最低量、交換単位、最大量はネイティブ数量で判定する。固定手数料と複雑な条件は数量概算へ勝手に織り込まない。

交換ルートは交換関係の連続した列で、数量を持たない。次の交換元は前の交換先と一致させ、同じ制度へ戻る循環を禁止する。各ステップの `preferred_rule_id` は参考値。現在無効なら有効な代替版を探す。候補が一意に定まらなければ概算を止める。シミュレーションは各制度のネイティブ数量を順番に計算し、交換単位に満たない端数を表示する。手数料や複雑な条件があるときは「条件により変動」と表示する。所要日数の合計は参考値であり、着弾日の保証ではない。

ルート詳細から移行計画の確認画面を開き、各ステップの現在有効なルール、口座、数量、着弾予定日を確定して保存できる。通常ルールとキャンペーンが併存するときは明示選択する。保存時に参照ルールと予定数量をステップへ固定し、後からルールを改定しても再計算しない。手数料や複雑な条件を含むルールは手動移行を使う。
